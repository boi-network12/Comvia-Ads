# 🚀 Comvia Ads

> **Create once. Advertise everywhere.**

Comvia Ads is a modern advertising platform that simplifies the process of creating, managing, and optimizing digital advertising campaigns across multiple advertising networks from a single dashboard.

Built for businesses, startups, agencies, and marketers who want to launch campaigns without navigating multiple complex ad managers.

---

## ✨ Features

* 🎯 Create campaigns in minutes
* 🌍 Target specific countries and regions
* 🖼️ Upload image or video creatives
* 🔗 Add custom landing page URLs
* 💰 Flexible budgeting
* 📊 Campaign performance dashboard
* 📈 Analytics and reporting
* ⚡ Fast and responsive interface
* 🔒 Secure authentication
* 📱 Fully responsive design

---

## 🎯 Vision

Advertising shouldn't be complicated.

Comvia Ads aims to make online advertising simple, accessible, and efficient by allowing businesses to create a campaign once and manage it from one intuitive platform.

Whether you're promoting a local business or launching a global campaign, Comvia Ads is designed to reduce complexity while maximizing reach.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/boi-network12/Comvia-Ads.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
